# 🎮 GameStore – Online Game Store Android App

## 📖 Description

A modern online game store Android app built using Kotlin and Firebase featuring real-time data, authentication, and a complete production-style architecture.

---
![Demo App](/app/src/main/res/drawable/maxresdefault.jpg)

---

## 📱 About

GameStore is a fully functional Android application that simulates a real-world online game marketplace.

The app covers complete app development including UI design, backend integration, real-time updates, and authentication systems.

This project was built live during a coding session to demonstrate how professional Android applications are created from scratch.

---

## 🚀 Features

- User authentication with Firebase  
- Real-time game listings  
- Modern UI design  
- Live data updates  
- Firebase backend integration  
- Clean architecture structure  
- Beginner to advanced friendly code  

---

## 🛠 Tech Stack

- Kotlin  
- Firebase Authentication  
- Firebase Realtime Database / Firestore  
- Android Studio
